    tcirviz
    
  
    Shows how the TornadoVM TC compiler turns a Java kernel into GPU code, one stage at a time. Nothing runs on a GPU: compilation is headless.
    
  
      
    
    • Pipeline: every stage and optimisation pass, with the IR size after it. Click a chip to show it in the middle pane, Shift-click for the right pane. ←/→ step through the pipeline.
      • 
    
    • Follow: click a Java line, a bytecode, an IR value (%x) or a line of target code. Every pane highlights what belongs to it (defines uses same Java line), and the Journey lists its path from Java to target code: where it is created, changed and removed, and by which pass.
      • 
    
    • Diff: a pane's Δ button shows what the stage changed against the previous one.
      • 
    
    • Targets: CUDA, OpenCL, Metal (experimental). New targets plug in as a Java service (io.github.mikepapadim.tcirviz.backend.Backend).
      • 
    
    • Keys: Ctrl+Enter compile · Esc clear the selection · ? this help.
